# Chess In C
A 2D chess game programmed in pure C with graphics from the raylib library. Project-based learning for getting comfortable in C. To be enjoyed locally with a friend.

To compile, make sure to have raylib [installed](https://github.com/raysan5/raylib/wiki/Working-on-macOS) and navigate to the src folder to run: <br />

```
eval cc chess.c $(pkg-config --libs --cflags raylib) -o ChessGame
```
